# 🧠 PerformLabs Brain (vault de Obsidian)

El **segundo cerebro** del proyecto: el conocimiento vivo de PerformLabs en notas
markdown enlazadas. Pensado para abrirse con **Obsidian** y para que **Claude Code**
lo mantenga al día.

## Cómo abrirlo

1. Descarga [Obsidian](https://obsidian.md) (gratis).
2. **Open folder as vault** → elige esta carpeta `brain/`.
3. Empieza por [[Home]] y abre la **vista de grafo** (icono de grafo en la barra
   lateral) para ver cómo conecta todo.

> Las notas usan `[[wikilinks]]`: al hacer clic saltas entre ideas; el grafo se
> dibuja solo a partir de esos enlaces.

## Qué hay dentro

- [[Home]] — el mapa de todo.
- [[Vision]], [[Posicionamiento]], [[Modelo de negocio]], [[Pagos]], [[Mercado y competencia]].
- [[Features]], [[IA y coste]], [[Sistema de diseño]], [[Arquitectura]],
  [[Infraestructura]], [[Roadmap]], [[Decisiones]], [[Glosario]].

Los documentos largos (estudios, modelo financiero, contrato) viven en
`docs/strategy/` y se enlazan desde aquí.

## Cómo se mantiene

Cuando tomamos una decisión o construimos algo grande, Claude Code:
1. Actualiza la nota correspondiente.
2. Añade una entrada en [[Decisiones]].
3. Mantiene los `[[wikilinks]]` para que el grafo siga siendo navegable.

Si quieres que capture una idea nueva, dímelo y la añado como nota enlazada.
