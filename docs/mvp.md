# MVP

## Versión 0.1

Objetivo: demostrar y vender la plataforma a entrenadores sin depender de terceros.

Incluye:

- Consola central.
- App PWA de miembro.
- Branding básico por workspace.
- Miembros mock.
- Rutinas mock.
- Comidas mock.
- Progreso mock.
- CMS mock.
- Estructura lista para base de datos.

## Versión 0.2

- Autenticación.
- Base de datos.
- CRUD de miembros.
- CRUD de ejercicios.
- CRUD de comidas.
- CRUD de contenido.
- Subida de imágenes.

## Versión 0.3

- Stripe.
- Estados de suscripción.
- Emails transaccionales.
- Check-ins reales.
- Generación de planes por plantilla.

## Versión 1.0

- Multi-tenant por dominio.
- Chat.
- Comunidad.
- Notificaciones.
- Analítica por entrenador.
